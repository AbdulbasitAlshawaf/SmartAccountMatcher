# المطابق الذكي للمحاسبة — مشروع أندرويد أولي

## الصيغ المدعومة في واجهة الاستيراد
- PDF يحتوي نصاً قابلاً للاستخراج.
- Excel بصيغتي XLS وXLSX.

## تشغيل المشروع
1. فك ضغط الملف.
2. افتح Android Studio واختر مجلد `SmartAccountMatcher`.
3. انتظر مزامنة Gradle.
4. شغّل التطبيق على هاتف أندرويد أو محاكي.

## ما يعمل الآن
- واجهة عربية.
- استيراد ملفين PDF أو Excel.
- استخراج النصوص/الخلايا.
- مقارنة أولية للقيم الرقمية الموجودة في الملفين.

## حدود مهمة
هذه نسخة تجريبية أولية وليست مطابقة محاسبية كاملة، ولا تحتوي بعد على تحليل ذكاء اصطناعي أو تصدير تقرير Excel. مقارنة الأرقام وحدها قد تخلط بين التواريخ وأرقام السندات والأرصدة والمبالغ. يجب تطوير محلل الحركات واختبار النتائج على كشوف فعلية قبل الاعتماد عليها محاسبياً.
